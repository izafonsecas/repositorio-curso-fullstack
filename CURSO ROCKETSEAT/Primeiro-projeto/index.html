PROJECTS

Projeto Energia Solar

HTML5 • CSS3 • Flexbox

Desenvolvimento de uma Landing Page de alta conversão focada no setor de energias renováveis. O projeto foi estruturado com HTML5 semântico para otimização de SEO e acessibilidade. No CSS, utilizei o sistema de Flexbox para garantir um layout totalmente responsivo e moderno. O destaque técnico foi a criação de componentes de 'Call to Action' estilizados com transições suaves (transitions) e estados de interação (hover), focando na experiência do usuário (UX) e na performance de carregamento.

Projeto Mobilidade Elétrica

CSS Grid • Design System • UI

Interface web dedicada à promoção de soluções em mobilidade sustentável. Neste projeto, foquei na implementação de um Design System consistente, utilizando variáveis CSS para gestão de cores e tipografia. Apliquei técnicas avançadas de CSS Grid para organizar a exibição dos serviços de forma modular e escalável. O código foi desenvolvido seguindo boas práticas de organização, facilitando a manutenção futura e a integração com frameworks de backend no futuro
