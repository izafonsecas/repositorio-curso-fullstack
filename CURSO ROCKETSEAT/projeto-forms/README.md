# Sobre o projeto

Este projeto foi desenvolvido como parte do desafio do Curso de FullStack da Rocketseat, com o objetivo de praticar os fundamentos de HTML e CSS através da construção de um gerador de convites para eventos.

A aplicação permite ao usuário preencher todos os dados de um evento (título, datas, local, descrição) e personalizar visualmente o convite com diferentes temas, cores e estilos.

# Funcionalidades

- ✅ Formulário completo com dados do evento
- ✅ Validação nativa de campos obrigatórios
- ✅ Seletor visual de cor principal (10 opções)
- ✅ Grade de temas com imagens
- ✅ Botões interativos Presencial / Online
- ✅ Toggle switch para alternar estilo Claro / Escuro
- ✅ Upload de imagem de capa
- ✅ Layout 100% responsivo
- ✅ Dark mode com paleta cuidadosamente escolhida

# Tecnologias

- HTML5: estrutura semântica e validação nativa
- CSS3: estilização, animações e responsividade
- Font Awesome: biblioteca de ícones

# Conceitos estudados

Durante o desenvolvimento, foram estudados e aplicados diversos conceitos:

- Estrutura semântica do HTML
- CSS Variables (Custom Properties)
- Flexbox e CSS Grid
- Pseudo-classes (`:hover`, `:focus`, `:checked`, `:invalid`)
- Pseudo-elementos (`::before`, `::after`, `::placeholder`)
- Posicionamento (`position: relative` e `absolute`)
- Transformações e transições CSS
- Media queries para responsividade
- Técnica de radio/checkbox escondido com label estilizado
- Animações (toggle switch deslizante, hover de cards)
- Validação nativa de formulários

# Como executar localmente

1. Clone o repositório:
```bash
git clone https://github.com/izafonsecas/repositorio-curso-fullstack/tree/main/CURSO%20ROCKETSEAT/projeto-forms
```

2. Acesse a pasta do projeto:
```bash
cd gerador-de-convites
```

3. Abra o arquivo `index.html` no seu navegador.
