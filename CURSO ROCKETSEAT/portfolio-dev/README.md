Bem-vindo ao repositório do meu portfólio profissional. 
Este projeto foi desenvolvido para consolidar minha transição de carreira da fisioterapia e marketing para a engenharia de software. 
Aqui, a tecnologia é a ferramenta, mas o foco é sempre o resultado de negócio.

🚀 Sobre Mim
Localização: Santarém, Portugal.
Background: 16 anos como fisioterapeuta e empresária; 5 anos em marketing e estratégia de social media.
Foco Atual: Desenvolvimento Full-Stack com ênfase em arquiteturas que impulsionam o crescimento empresarial e a eficiência operacional.

🛠️ Tecnologias e Ferramentas
Frontend: HTML5, CSS3 (Grid, Flexbox), JavaScript (React).
Backend: Python (Django/Flask), SQL.
Estratégia: Automação de Marketing, Análise de Dados e Implementação de IAs.

📂 Projetos em Destaque
1. Plataforma de Prospecção e CRM Solar (WCS Energia)
Desenvolvimento de solução back-office para gestão de rotas comerciais e leads qualificados. O projeto foca na otimização de vendas consultivas para instalação de usinas solares, integrando planejamento logístico e análise de economia de fatura.

2. Portal de Serviços de Segurança (Rede de Proteção PT)
Interface focada em UX para serviços de segurança residencial em Portugal. Prioriza a hierarquia de informação e performance para converter visitantes em pedidos de orçamento diretos.

3. Dashboard Logístico (Carrega e Vai)
Estruturação de interface para visualização de métricas de transporte, facilitando o acompanhamento de fluxos de carga em tempo real.

4. Portal Tech - Santarém
Projeto de estudo focado em layouts complexos com CSS Grid, apresentando um portal de imagens responsivo sobre a região de Santarém.
